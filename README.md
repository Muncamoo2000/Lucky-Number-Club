# Lucky-Number-Club
A Python number guessing game built with Tkinter. Players guess a randomly generated number between 1 and 100, receive higher or lower hints, track their attempts, and compete against their personal best scores on a leaderboard.

# Lucky Number Club

## Project Overview
Lucky Number Club is a number guessing game built with Python and Tkinter. The application generates a random number between 1 and 100 and challenges the player to guess it using the fewest attempts possible.

## Features
- Random number generation between 1 and 100
- Interactive graphical user interface built with Tkinter
- Higher and lower guessing hints
- Input validation and error handling
- Attempt counter
- High score leaderboard
- New Game functionality
- Enter key support for submitting guesses

## Technologies Used
- Python
- Tkinter
- Random module

## How to Run
1. Download or clone this repository.
2. Open the project in a Python IDE.
3. Run `lucky_number_club.py`.
4. Enter a number between 1 and 100 and start guessing!
